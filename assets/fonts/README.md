# Fonts (self-hosted, subset to Latin, WOFF)

- **Inter** 300 / 400 / 500 — SIL Open Font License 1.1 (https://rsms.me/inter/). Static cuts, Latin subset.
- **Lora** variable roman and italic, weights 400–700 — SIL Open Font License 1.1 (https://github.com/cyrealtype/Lora-Cyrillic). Latin subset.

Served from this folder so the site needs no font CDN. Declared in `css/tokens.css`.
